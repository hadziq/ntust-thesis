## Adding Yourself

When your pull request is merged, please add a row for yourself to the **Code & Documentation Contributors** table above (in the same PR is fine), using this format:

```markdown
| <img src="https://github.com/USERNAME.png?size=60" width="40" alt="USERNAME"/> | **Your Name** — [@USERNAME](https://github.com/USERNAME) | Short description of your contribution ([#PR](https://github.com/hadziq/ntust-thesis/pull/PR)). |
```

If you contributed in a way that doesn't show up in the commit history (bug reports, testing against new NTUST rules, helping other students), you deserve a row too, so open a PR or an issue.

The full commit history is available on the [contributors graph](https://github.com/hadziq/ntust-thesis/graphs/contributors).
