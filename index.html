Get started in four steps四個步驟開始撰寫

  1. Install a TeX distribution安裝 TeX 環境

    Use a recent請安裝最新版的 MacTeX (macOS), MiKTeX or或 TeX Live (Windows / Linux). XeLaTeX and BibTeX are included.其中已包含 XeLaTeX 與 BibTeX。

  2. Get the template取得範本

    Download the ZIP, fork the repository, or clone it:下載 ZIP、Fork 本倉庫，或直接 clone：

    git clone https://github.com/{{ site.repository }}.git

  3. Pick an edition & install the fonts選擇版本並安裝字型

    Work inside English Version/ or 中文版本/. Install 標楷體.ttf from that folder and make sure Times New Roman is available.在 English Version/ 或 中文版本/ 資料夾內作業。安裝該資料夾中的 標楷體.ttf，並確認系統已有 Times New Roman。

  4. Compile編譯

    Run the build script, then open my_ntust_thesis.pdf. See other ways to compile.執行編譯腳本後開啟 my_ntust_thesis.pdf。其他方式請見編譯方式。

    cd "English Version"   # or: cd 中文版本
bash my_ntust_thesis.sh

Which files do I edit?要修改哪些檔案？

Rule of thumb: edit files whose names start with my_, plus your chapters in sections/. Files starting with ntust_ define the official layout and should stay untouched. 原則上只修改檔名以 my_ 開頭的檔案，以及 sections/ 中的各章檔案。以 ntust_ 開頭的檔案為學校規定格式，請勿更動。

Compiling編譯方式

The table of contents, cross-references, and bibliography need the full sequence xelatex → bibtex → xelatex → xelatex. Pick whichever way suits you. 目錄、交互參照與參考文獻需要完整的編譯流程 xelatex → bibtex → xelatex → xelatex。請選擇適合你的方式。

macOS / Linux, from inside the edition folder:macOS / Linux，在版本資料夾內執行：

bash my_ntust_thesis.sh

Works on every platform, including the Windows command prompt:適用於所有平台，包括 Windows 命令提示字元：

xelatex my_ntust_thesis.tex
bibtex  my_ntust_thesis
xelatex my_ntust_thesis.tex
xelatex my_ntust_thesis.tex

latexmk (bundled with TeX Live and MacTeX) reruns XeLaTeX and BibTeX as often as needed:latexmk（TeX Live 與 MacTeX 皆已內建）會自動重複執行 XeLaTeX 與 BibTeX 直到結果穩定：

latexmk -xelatex my_ntust_thesis.tex

With the LaTeX Workshop extension, add this recipe to your settings.json:使用 LaTeX Workshop 擴充套件時，將以下設定加入 settings.json：

"latex-workshop.latex.recipes": [
  {
    "name": "xelatex ➞ bibtex ➞ xelatex × 2",
    "tools": ["xelatex", "bibtex", "xelatex", "xelatex"]
  }
],
"latex-workshop.latex.tools": [
  {
    "name": "xelatex",
    "command": "xelatex",
    "args": ["-synctex=1", "-interaction=nonstopmode", "-file-line-error", "%DOC%"]
  },
  {
    "name": "bibtex",
    "command": "bibtex",
    "args": ["%DOCFILE%"]
  }
]

Tip: while drafting, comment out the \input{frontpages/…} and \input{backpages/…} lines in my_ntust_thesis.tex to compile faster. 小技巧：撰寫草稿時，可在 my_ntust_thesis.tex 中將 \input{frontpages/…} 與 \input{backpages/…} 註解掉，以加快編譯速度。

FAQ & troubleshooting常見問題與疑難排解

fontspec error: "font-not-found" — what now?出現 fontspec error: "font-not-found" 怎麼辦？

For AR PL KaitiM Big5, install 標楷體.ttf from the edition folder and recompile. For Times New Roman, install the font, or change \setmainfont{…} in my_ntust_thesis.tex to a font you have, such as TeX Gyre Termes, a free Times clone included in TeX Live.若找不到 AR PL KaitiM Big5，請安裝版本資料夾中的 標楷體.ttf 後重新編譯。若找不到 Times New Roman，請安裝該字型，或將 my_ntust_thesis.tex 中的 \setmainfont{…} 改成已安裝的字型，例如 TeX Live 內建、與 Times 相近的免費字型 TeX Gyre Termes。

The table of contents or citations show ??目錄或引用顯示 ??

A single xelatex run is not enough. Run the full sequence (or latexmk -xelatex) so BibTeX and the cross-references can resolve.只執行一次 xelatex 是不夠的。請完整執行四次編譯流程（或使用 latexmk -xelatex），讓 BibTeX 與交互參照能正確產生。

Can I compile with pdfLaTeX?可以用 pdfLaTeX 編譯嗎？

No. The template uses fontspec and xeCJK, which require XeLaTeX. pdfLaTeX fails with font and CJK errors.不行。本範本使用 fontspec 與 xeCJK，必須以 XeLaTeX 編譯；使用 pdfLaTeX 會出現字型與中文相關錯誤。

How do I turn on the NTUST watermark?如何加上臺科大浮水印？

It is off by default. Uncomment this line in common_env.tex of your edition:浮水印預設為關閉。請在所用版本的 common_env.tex 中取消以下這行的註解：

\input{watermark/ntust_watermark.tex}
Where do the recommendation letter and approval form go?指導教授推薦書與口試委員審定書放在哪裡？

The template reserves blank pages for both and lists them in the table of contents. After your oral defense, replace those pages with the signed scans before binding.範本已為兩者預留空白頁並列入目錄。口試完成後，在裝訂前將這些頁面替換為已簽名的掃描檔即可。

Can I use Overleaf?可以在 Overleaf 上使用嗎？

Usually, with a few changes. Upload one edition folder as a new project and set the compiler to XeLaTeX in the project menu. Overleaf cannot see fonts installed on your computer, so you may need to load the bundled font by file name and switch the Latin font to TeX Gyre Termes. The maintainers do not test on Overleaf, so please report what worked for you.通常可以，但需做些調整。將其中一個版本的資料夾上傳為新專案，並在選單中將編譯器設為 XeLaTeX。Overleaf 無法使用你電腦上安裝的字型，因此可能需要以檔名載入附帶的字型，並把英文字型改為 TeX Gyre Termes。維護者並未在 Overleaf 上測試，歡迎分享你的做法。

Is this the official NTUST template? Is it up to date?這是學校官方範本嗎？是否為最新格式？

It is a community template, not an official NTUST release. Its settings were last aligned with the 2018 dissertation submission rules. Formatting rules change, so check the current guidelines from your department and the NTUST library, and send a pull request if something is out of date.本範本由社群維護，並非學校官方版本，設定最後依 2018 年的論文繳交規定更新。格式規定可能變動，請以系所及圖書館最新規定為準；若發現不符之處，歡迎提交 Pull Request。
